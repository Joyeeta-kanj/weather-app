# weather-app
A responsive weather application built with React.js that allows users to search for a city and view its current weather conditions and forecast.
The app uses the Open-Meteo Geocoding API to find the location coordinates of a searched city and the Open-Meteo Weather API to fetch weather information. It displays details such as temperature, weather conditions, and upcoming forecasts through an interactive and user-friendly interface.

Key features includes searching weather by city name, displaying current temperature and weather conditions, view upcoming weather forecasts, visualise temperature trends using a line graph, and fetch real-time weather data using APIs. 
Technologies like React.js, JavaScript, CSS, HTML, REST APIs, Open-Meteo API and recharts.
